Cortex Anywhere: the day zero design, running on Windows

The day zero architecture was built for our own servers. Here the same codebase runs as a single customer install on a real Windows Server 2022 with no GPU, installed as code, attacked, rebooted and timed. How it was done, phase by phase: the proof.

Fail closed, everywhere. Right tenant's data, or no data. Same rule, same database guarantee, on a customer's machine and on our servers.

3 · One agent run

The model is treated as untrusted at every step

sequenceDiagram
  participant U as User
  participant R as AgentRuntime
  participant DB as Postgres (RLS)
  participant M as Qwen3
  U->>R: input (tenant from TenantContext)
  R->>DB: recall: nearest notes, tenant pinned
  R->>M: system prompt + user turn with recalled notes as data
  M-->>R: answer or tool call
  R->>R: tool on the allow list? else refuse and record
  R->>R: output gate: strip reasoning and images
  R->>DB: memory item + episode + audit, one run_id
  R-->>U: answer
