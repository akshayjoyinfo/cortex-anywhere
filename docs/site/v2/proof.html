The rules I worked by
  • Evidence over slides
  • Nothing installed by hand
  • Every artifact pinned by hash
  • Binaries built in CI, never on the target
  • Every run writes JSON evidence
  • Stop after each phase, report numbers
  • Mark what is unverified

What is real today

  • Install as code: 12 components, pinned, drift checked
  • PostgreSQL + pgvector with FORCED RLS
  • Local profile: Windows auth, DPAPI, loopback only
  • Agent loop, tool allow list, output gate
  • Memory with provenance, encrypted, audited
  • Leak suite and hostile corpus, 0 leaks
  • Windows service, survives reboot
  • CI releases with hash and provenance
